A make.fun entry for [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d): the one line a smart fridge would text its owner at 3am.

The fridge has been awake all night keeping count, and at 3am it finally files the leftovers' complaint — in the owner's own handwriting.

## The line

> "The leftovers have started a petition. 41 signatures. All of them are the same handwriting. Mine."

## How it works

`main.py` (pure Python stdlib) writes the line byte-exact to `/output/entry.txt`, with no trailing newline. Run it with:

```sh
python3 main.py
```
